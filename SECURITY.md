# Security Policy

## Supported versions

Security fixes are provided for the latest published LuckyDrop release.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** private reporting form in the
repository's Security tab when it is available.

If private vulnerability reporting is not available, open a public issue that
asks a maintainer to establish a private contact channel. Do not include
exploit details, personal data, credentials, or other sensitive information in
that issue.

Include the affected version and platform, the security impact, reproduction
conditions, and any suggested mitigation in the private report. Maintainers
will acknowledge the report, investigate it, and coordinate disclosure and a
fix as appropriate.

Please do not publicly disclose an unpatched vulnerability before maintainers
have had a reasonable opportunity to respond.
